<analysis_contract>
- The only approved header shape is an integer induction variable declared and initialized to literal zero, a less-than condition whose left operand resolves to the same variable, and prefix or postfix increment of that variable. Transparent `ImplicitCastExpr` and `ParenExpr` wrappers may be ignored. Other header shapes are unsupported per D-04.
- Within a loop, `break`, `goto`, `return`, indirect goto, inline assembly, or missing structure needed to prove the header/body rules makes the loop unsupported. An ordinary return from a pure scalar helper, such as `square`, is not by itself a helper hazard.
- A scalar declared inside the loop body may be written. A loop-level array or pointer-parameter subscript write is candidate-safe only when its normalized index is exactly the recognized induction variable. Global array writes, dereferences, pointer writes in helpers, shared scalar writes, and other subscripts are unsafe per D-05 and D-07.
- Classification precedence is deterministic: incomplete/noncanonical/control structure is unsupported; otherwise direct or reachable safety hazards are unsafe; only a canonical loop with no hazard is safe. Unknown information never proves safety.
- Functions, edges, loops, summaries, codes, and evidence are sorted by source location then stable names/values. A propagated witness begins at the loop's containing function and ends at the terminal hazardous helper.
</analysis_contract>
</context>

## Trust Boundaries

| Boundary | Description |
|---|---|
| Validated JSON AST -> semantic facts | Clang output is structurally variable; node identity, target resolution, ownership, and locations cannot be assumed. |
| Direct facts -> local call graph | Only proven local edges may be traversed; unresolved or external calls must remain hazards. |
| Call graph -> loop decision | Recursive or adversarial graph shape must terminate and uncertainty must never become approval. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-06 | Spoofing | `CallExpr` target resolution | mitigate | Resolve local callees from Clang declaration identity and the set of source-owned definitions; do not infer locality from a matching display name. Missing/indirect targets emit `UNKNOWN_CALL`. |
| T-01-07 | Tampering | Write/effect classification | mitigate | Preserve target kind, index variables, global ownership, pointer provenance, and source evidence in immutable facts; classifier tests cover global, pointer, scalar, and index boundaries explicitly. |
| T-01-08 | Denial of Service | `summarize_functions` cycles | mitigate | Use explicit graph state or deterministic SCCs, process a finite set of local functions/edges, deduplicate evidence, and test self and mutual recursion termination. |
| T-01-09 | Elevation of Privilege | `classify_loops` safe decision | mitigate | Require positive proof of the full canonical header plus exact induction-indexed writes and absence of all direct/transitive hazards; missing facts select unsupported or unsafe, never safe. |
| T-01-10 | Repudiation | Transitive decision evidence | mitigate | Keep stable reason enums, source locations, direct versus transitive origin, and a deterministic call-chain witness for every propagated terminal cause. |
| T-01-SC | Tampering | npm/pip/cargo installs | accept | No install task exists; these modules and tests use only the Python standard library and Plan 01-01 contracts. |

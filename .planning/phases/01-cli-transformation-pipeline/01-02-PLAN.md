## Artifacts this phase produces

This plan owns the eight-file user-facing share of the Phase 1 artifacts; it consumes but does not modify the eight capture-foundation files owned by Plan 01-01.

| File | Contract produced | Required fields, functions, or behavior |
|------|-------------------|------------------------------------------|
| iris_analyzer/reporting.py | Report contract | sanitize_component(value), write_report(...); stable JSON, Markdown, and .ll artifacts |
| iris_analyzer/cli.py | CLI contract | build_parser(), parse_args(argv), validate_source(path), main(argv=None) returning an integer exit code |
| iris_analyzer/__main__.py | Module entry point | raise SystemExit(main()) so python -m iris_analyzer works |
| tests/test_reporting.py | Report contract tests | Schema, deterministic contents, safe destination behavior, sanitization, filenames, and links |
| tests/test_cli.py | CLI contract tests | Argument validation, orchestration order, success output, and bounded failures |
| tests/test_integration.py | Real-Clang smoke proof | Conditional module-command run against the checked-in example with artifact assertions |
| examples/loop.c | Demo source | A small deterministic loop that yields at least two retained snapshots on the available Clang toolchain |
| README.md | First-run contract | Python and Clang prerequisites, exact command, options, report layout, limitations, safety, and test command |

The analyze subcommand must expose exactly these Phase 1 inputs:

| CLI input | Meaning | Default/validation |
|-----------|---------|--------------------|
| SOURCE | One positional C source path | Must exist, be a regular file, and have the exact .c suffix |
| --clang EXECUTABLE | Clang path or command-name override | Omitted means resolve clang from PATH |
| --output DIRECTORY | Report destination | Omitted means ./SOURCE_STEM-iris-report; a non-empty existing destination is rejected without deleting user files |
| --max-snapshots N | Global retained-snapshot cap after per-scope filtering | Positive integer; default 50 |

The manifest contract is schema_version, source, clang, optimization_level, command, captured_count, retained_count, max_snapshots, truncated, and snapshots. Each snapshots item contains index, pass_name, scope, and file, where file is a relative snapshots/NNN-sanitized-pass-name.ll path. Manifest keys and snapshot ordering are stable across repeated equivalent runs.
